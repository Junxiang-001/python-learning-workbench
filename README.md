# Python 学习工作台

一个**零依赖、零构建**的浏览器端 Python 学习应用：双击 `index.html` 就能用，不联网、不装包。

- **练习场**：浏览器里真实执行 Python，真的报错、真的输出（不是正则猜对错）
- **今日复习**：先自己想再看答案，按遗忘曲线（1/3/7/15 天）排期
- **思维导图 / 速查 / 番茄钟**：路线与元信息随查随用

定位：这是一个工作台，不是一门课——每天跑通一件具体的小事。

## 怎么跑测试

需要 Node.js 18+（用到内置 `node:test`）：

```bash
node --test
```

全绿才能提交。测试覆盖：备份/恢复、69 道练习题与参考答案、37 张复习卡片排期、pyexec 语法回归。

## 目录说明

| 路径 | 内容 |
|---|---|
| `index.html` | 入口页（双击打开） |
| `app.js` | 应用主控与视图切换 |
| `pyexec.js` | 浏览器内 Python 执行器（被页面与 Node 测试共用） |
| `exercises.js` / `exercises-bank.js` | 练习场逻辑 / 题库数据 |
| `review.js`、`method.js`、`fun.js` | 复习排期、学习方法、彩蛋 |
| `data-*.js` | 思维导图 / 内容 / 记忆数据 |
| `tools/` | 题库构建与校验脚本（`build-bank.js` 由 MBPP 数据生成题库） |
| `tools/mbpp/` | MBPP 基准数据集（题库原料） |

## 开发约定

1. **零构建约束**：不引入打包器、框架、npm 依赖；脚本一律普通 `<script>` 标签（保证 `file://` 双击可用）
2. **缓存戳**：改动 `js/css` 后把 `index.html` 里对应 `?v=` 日期戳更新一下，避免浏览器拿旧缓存
3. **渐进拆分**：改到哪个大文件，才把其中独立逻辑块拆成新文件；每次拆分单独提交
4. **提交前**必须 `node --test` 全绿；意外发现先报告，不擅自扩大改动范围
5. 排查报错先看 [排查手册](docs/排查手册.md)
