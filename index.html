    学代码除了 Python 还需要什么？

    小白最常见的困惑一次说清。你的电脑已装好 Python 3.14，下面按优先级来。

    资源导航

    精选不贪多，每个都标了怎么用。

    成就墙

    记笔记、做练习、复习卡片、完成番茄都能拿经验值。成就只是记录，不是目的。

    经验值规则

    • 学完一章 +20 XP
    • 写一篇像样的笔记（80 字以上）+10 XP
    • 拆开一个记忆包 +5 XP
    • 完成一个番茄钟 +8 XP
    • 路线清单每勾一项 +5 XP
    • 练习通过 +10 XP · 不看答案重写一遍通过 +15 XP
    • 复习满 5 张卡 +6 XP
    • 每天打卡 +3 XP

    这个工作台为什么这么设计

    每一块界面背后都对应一条学得更快的方法。知道为什么，你才不会把它当成打卡游戏。

    先说一个绕不开的矛盾：「最快」和「最牢」是要打架的。追求最快，很容易变成看了一堆视频感觉很懂、一动手全是空白。所以这里追求的「快」，是少走弯路的快，不是跳过必要时间的快。

    做事的五步
    01

    先定「用来做什么」，再定「学什么」

    「最有用」只来自这里。不要定「我要学 Python」，要定「两周后我要能写一个自动整理 Excel 的脚本，交给同事用」。目标必须是能交出去、会被检验的东西。没有这个，学习就是囤积，而囤积会给你一种很舒服的错觉。

    在这个工作台里：首页的「我要做出来的东西」；学习路线的每个阶段都绑定一个可交付产物。

    02

    先跑通一个粗糙的完整闭环

    学语言先说出十句能用的句子，学编程先写出一个能跑的丑脚本。一整个流程哪怕粗糙，也胜过十个精致的一半。因为只有跑通了，你才知道哪个基础是真的在卡你；在那之前啃的书，八成用不上。

    在这个工作台里：学习路线的第一阶段就叫「今天跑通」；练习场第一题是 print，第十题是九九乘法表，中间没有一步是「先把语法看完」。

    03

    用输出学，不用输入学

    看书、听课、看视频都是「识别」，识别会给你虚假的掌握感——大脑认得它的时候，会像已经会了一样舒服。真正留下的是「提取」：合上书复述一遍、给别人讲一遍、从空白写出代码。费曼技巧的本质就是这个。

    在这个工作台里：复习卡的正面永远是一个问题，答案藏在后面；练习场通过之后会反问你一句「不看答案能重写吗」——答「能」就把编辑区清空，写出第二遍才记「已掌握」。

    04

    把反馈回路缩短到几分钟

    这是最被低估的变量。有编译器报错、有人当场纠正、有工具逐行指出问题，和「看完一本书、一个月后才用得上」相比，学习速度可能差一个数量级。反馈越慢，你就在错误的路上多积累一天。

    在这个工作台里：练习场内置了一个真的 Python 解释器，你的代码真的被执行，报错带行号和中文解释——不是拿正则猜你写对没有。

    05

    在能力边缘上练

    太简单是重复，太难是挫败。要落在「努力一下能做成、但要费点劲」的位置。不舒服，但不痛苦。这也是为什么练习场有难度分级和渐进提示——卡住时先给你一级提示，而不是直接给答案。

    在这个工作台里：练习场分入门 / 进阶 / 挑战三档，每题有三层递进提示和参考答案（先自己写，卡住了再看）。

    在时间维度上的三条
    06

    分散，而不是集中

    同样练三小时，拆成六天每天半小时，胜过一天练完。遗忘不是敌人，是机制：在快要忘的时候想起来的，才真的被记住。所以复习要比学习更守时。

    在这个工作台里：「今日复习」按 3 天 → 7 天 → 15 天这样拉长间隔；答错的卡当天就会再出现一次。

    07

    交错练习，别一个章节连刷

    把不同类型的题目混着做，比一类一类刷效果好——虽然感觉更差。因为混着做逼你先判断「这是哪一类问题」，而在真实场景里，判断题型本来就是一半的工作量。

    在这个工作台里：复习队列按章节轮转，相邻两张几乎不会来自同一章；练习场按课程章节排列、难度分三档，让你能跟着课程往前走，同时一眼看到自己处在哪一档。

    08

    理解只要一次，自动化要几百次；建结构，别记碎片

    语言、编程、乐器、写作，瓶颈基本都不在「懂不懂」，而在「能不能不假思索地做出来」。这个阶段没有捷径，只有高频、短时、分散地练。同时每学一个点，问自己：它挂在我已知的哪个东西上？为什么是这样而不是那样？专家和新手的差别不在记了多少条，而在怎么组织。

    在这个工作台里：思维导图给你骨架，记忆包给你「为什么是这样」的来龙去脉，速查表让你不必背细节——把记忆外包出去，把理解留在脑子里。

    如果只记一个动作：给自己定一个两周内要交出去的小东西，做它的过程中缺什么学什么；做完找人（或 AI）挑毛病，然后重做一遍。这一轮下来，比读十本书管用。
